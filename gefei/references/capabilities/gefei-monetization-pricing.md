## I — 方法论骨架 (Interpretation)

1. **为什么能赚钱**：欧美用户时薪高，愿意为节省时间/提升效率付费（常见 $9.9–49.9/月），谷歌把这些用户免费送来；你赚的是"效率差 + 信息差"。
2. **选变现方式**：
   - 广告（AdSense 自动广告优先，正规、少扣量）：适合信息/游戏/轻工具、高流量低付费意愿；
   - 订阅/一次性付费：适合有算力成本或强效率价值的 AI 工具；
   - **广告 + 订阅**：新 SaaS 免登录免费用（Cloudflare Turnstile 防刷），广告覆盖 API 成本，积累用户行为数据与排名，再引导订阅。
3. **定价四阶段**：先上付费 → 涨价 → 上订阅 → 年付默认展示/优先展示。大胆定价：价格决定你抓到哪类人群；不要用国内定价逻辑，$99/月、$700–800/年的档位也有人买。
4. **算账公式**：
   - AdSense 月收入 ≈ 30 × (日UV/1000) × eCPM × (PV/UV) × (广告数/PV)；竞品 UV ≈ Similarweb 月访问 ÷ 30 ÷ 人均访问次数。
   - 目标倒推：目标月收入 → 日收入 → 每 UV 价值（广告+SaaS，作者默认约 $0.11）→ 日 UV → 目标排名 CTR → 关键词日搜索量 → 所需外链域名。
   - 投放前：LTV vs CAC、回本周期、现金回笼时点；小额测试。
5. **有流量没订单，先修漏斗**：落地页（首屏是否说清价值）→ 登录门槛 → 免费额度是否太多/太少 → 支付流程 → 价格档；看流量国家结构（低价值国家几乎零付费）。不要用批量上新站来掩盖未知变量。

- **投自己的品牌词（案例 2024-03-14，pagepilot.ai）**：一是承接那些第一次没付费、但记住了品牌名的回头用户，二是防止别人低价投你的品牌词截流。这是哥飞的推测。来源：https://github.com/hlwhut225/gefei-knowledge-base 路径 judgeKey/16-nz5kw1eht2.md（原文发布 2025-11-12）
- **群友出单经验（非哥飞本人，2025 群聊征集）**：有人"一开始送免费一直不出单，改成必须付费后天天出单"；有人把付费墙做成页面内弹窗而不是跳转；有人出单靠买 Toolify 导航带来约 30% 流量。只能作为参考。来源：https://github.com/hlwhut225/gefei-knowledge-base 路径 judgeKey/42-naadq5ctx7.md（原文发布 2025-10-15）

### 公众号补充（2026-11-06/11-08 文章，2026-11-09 整理）
- **新站刚有排名先别急着变现**：排名还不稳时先让网站成长；要变现就直接用这个域名申请 AdSense 或接支付，不要借老站广告账号绕路（哥飞因此丢了单日 1 万点击的排名）。来源：公众号《【哥飞SEO教程】设了 Canonical，谷歌还是收录了复制站：我单日 1 万点击的新站就这么掉了排名》(20261106)
- **按流量来源定价**：ChatGPT 用户偏年轻、爱尝鲜但钱不多，适合一次性小额付费包；谷歌用户各年龄段都有、量最大，可以免费试用再转化；必应用户偏中老年、多为 Windows 用户，喜欢简单直接、讨厌比价和意外收费（有群友年费定 1999 美金照样卖出去，群友案例）。来源：公众号《哥飞联合谷歌等一起在上海办了一场 AI 出海与增长探索峰会》(20261106，只取哥飞本人分享部分；其他嘉宾内容不并入)

### 案例 3：茄子投放算账（20260818，嘉宾稿）
- 花过上亿预算的经验：投之前先算 LTV/CAC/回本，否则越投越亏；对照 20250407 作者自己 Google Ads 500 块打水漂。原因是没设投放地区、默认全球投放；解法：限制投放地区白名单（如美、英、法、德、新西兰、澳大利亚），每日预算先小一点（如 200 元），观察注册、付费等转化再调整（20250407）。

## E — 可执行步骤 (Execution)

1. **画像与流量结构**：品类、成本结构（API 成本/用户）、流量国家占比、当前 UV/注册/付费。
2. **选模式**：按"付费意愿 × 单用户成本"选 广告 / 订阅 / 广告+订阅；写出理由。
3. **定价档**：月付、年付（默认展示，给折扣）、可选一次性/积分包；以竞品定价页为参照向上而非向下；免费额度=能体验到价值但不足以长期白用。
4. **算账**：用 AdSense 公式或订阅公式估月收入；目标倒推所需 UV 与关键词；如考虑投放，算 LTV/CAC/回本周期。
5. **漏斗排查（有流量无订单时）**：逐段列指标（访问→试用→注册→看价格→发起支付→成功），找掉得最狠的一段先修；同时检查低价值国家占比。
6. **输出**：变现方案（模式、价格表、免费额度、收入估算表、首要修复的漏斗环节、两周验证指标）。

## B — 边界 (Boundary)

- 默认参数（每 UV $0.11、eCPM、CTR）是经验值，因国家与品类差异巨大。
- AdSense 审核/政策、各国税务与支付合规不在范围；以官方政策为准。
- 定价案例来自作者与群友，有幸存者偏差；大胆定价需配合真实价值与退款政策。
- 嘉宾/群友稿（Niko、茄子）是单一来源经验。

- **别定太低**：单价越低，网关固定手续费占比越高；群友布衣 $1 试用价“钱都被支付网关拿走了”，后涨到 $9.9–$299（群友，articles/12-community/2025-08-26-布衣…md）。实际到手账：28 单付 $887.77，代扣税 $110.53、手续费 $59.81，到手 $717.43（哥飞 2025-04-03，articles/08-monetize/2025-04-03-一些有意思的出海产品小数据.md）。
- **新站先免登录免费用（哥飞本人 2025-01-13）**：一上来强制登录/付费会拦掉访客、拿不到用户行为数据和排名；用 Cloudflare 人机验证防刷，广告先回收 API 成本，再引导付费。实测：日 6.4K UV，AI 成本 469 元，广告 $133 + 3 笔 $9.9 仍小赚（articles/08-monetize/2025-01-13-SaaS-网站变现新模式：广告+订阅.md）。常见路径：未登录免费 1 次 → 登录送 2 次 → 用完付费（articles/10-scale/2025-10-16-广告投放-197-ROI…md）。
  - **与旧卡冲突**：旧卡引用群友“送免费不出单，改成必须付费后天天出单”。按优先级，**新站以哥飞本人“先免费、再引导”为准**；群友经验仅适用于已有排名、转化明显被免费额度吃掉的站。
- **广告与订阅能否并存——看数据不看观点（guide/11 Step 9）**：哥飞自己的 SaaS 是“免费用户看广告、付费免广告”；也有群友加 AdSense 后两天无单、跳出率升，撤掉后恢复。做法：加广告前后各看一周付费率/跳出率/排名。旧卡“广告约 $200/月就关掉（2024-08-07）”是个案，归入此判断规则下。
- **算账公式（2023-07-19）**：广告收入=访问量×曝光率×eCPM；付费收入=访问量×付费率×客单价。日入 $100：纯广告约需 7500 UV（eCPM $3.3、2 曝光/PV、2 PV/UV）；付费约需 333 新注册（3% 付费、首日 $10）（articles/01-direction/2023-07-19-如何做到通过小产品日入100美元？.md）。计算器 seo.box/calculator/money/。
- **同一批流量做订阅可达广告的十几倍**，结论“还是得做订阅，辅助上广告，靠免广告吸引付费”（guide/11 Step 2，社群小课堂转述）。哥飞 AdSense 分成 51%（articles/08-monetize/2024-12-18-聊聊广告主…md）。
- **AdSense 申请顺序（2025-09-01 实测）**：先放小写 ads.txt 并用 Ads.txt 验证 → 不要立即申请，切到“代码段”把 js 放进每页 head → 再点申请；放 js 可让谷歌看到流量、过审即开自动广告（articles/08-monetize/2025-09-01-【哥飞出海教程】Adsense-提交网站申请的小细节.md）。流量大审核就快；以前“域名满 3 个月才能申请”不可靠（guide/11 Step 4）。
- **过渡广告联盟**：Adsterra/Monetag 可过渡，但“广告太野”，必须关成人/赌博类；长期用 AdSense（guide/11 Step 4；articles/01-direction/2025-09-07-小游戏站赚美元攻略第1篇…md）。
- **eCPM**：游戏站千次 PV 约 $5–10，欧美可到十几二十美元（2024 年底，guide/11 Step 6）；高客单价行业（保险/理财/法律）、音视频类 AI 比图片类单价高。
