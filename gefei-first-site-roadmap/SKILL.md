# 零到第一个出海站：练手站台阶与阶段目标

## R — 原文 (Reading)

> 做网站就像是种树一样，先种下第一棵树，再种下第二棵树，慢慢你就有了一个小果园，收成会越来越好。
>
> — 哥飞，《养网站防老：网站可以做成一生的事业》(20231009)

> 就像游戏里的升级打怪，每一个等级都需要经历，你不可能什么都不做，然后就幻想能够日入1000刀。打基础，是一定要经过的阶段。练手站，是最好的打基础方式。
>
> — 哥飞，《来看看你目前收入属于哪个等级？》(20250206)

## I — 方法论骨架 (Interpretation)

哥飞给新手的路线不是"想一个好点子做大"，而是**放弃一站发思维，用一串越来越难的练手站把整条链路跑通**，每一站只追一个可验证的小目标：

1. **站 1：只走流程**（不求流量）——用品牌词/任意词，跑通 注册域名 → Cloudflare 解析 → GitHub+Vercel 部署 → GA → GSC 提交 → 被收录。
2. **站 2：低竞争词进前 10**——选 Ahrefs KD<10、进前 10 需要的外链域名 <10 的词，不看搜索量；目标约一周靠外链进前 10。
3. **站 3：100 点击/天**——选有真实搜索量的新词/蓝海词（约 3 周量级目标），开始接变现（AdSense 或付费）。
4. **之后：1000 点击/天、第一美元 → 日入 100 美元**——用收入目标倒推所需 UV、关键词搜索量和外链数（见 monetization 卡的倒推公式）。

贯穿原则：先从小词做起；快就是优势、完成比完美重要；做站的数量胜过单站憋大招；网站是可以长期养的资产（养网站防老）。

### 补充·第二批（来源：GitHub [hlwhut225/gefei-knowledge-base](https://github.com/hlwhut225/gefei-knowledge-base)，小课堂与案例拆解，2026-10-27 整理）
- **新手避坑清单（哥飞航海开船第一课，带 AI 工具站）**：找已经存在的需求，别自己凭空想；新手别做太大，一个月内要能做完；不要一上线就申请 AdSense，有流量后再申请；产品还没做就别去注册海外公司；"网站上线只完成了赚钱的 20%，剩下 80% 是推广"。他给的最小 MVP 路径是：找需求 → 做站（Replicate/HuggingFace API + v0）→ 提交 GSC、在社区发帖、上 Product Hunt、提交导航站 → 有流量后再接 AdSense。来源：https://github.com/hlwhut225/gefei-knowledge-base 路径 jinjiejiaocheng/04-xinshou-chuhai-diyizhan.md

## A1 — 原文中的应用 (Past Application)

### 案例 1：第一美元的倒推（20240620）
- **问题**：新人不知道"第一个订单"需要多少流量。
- **方法论的使用**：按 1% 转化，一单≈100 个谷歌点击/天；按 5% CTR，需≈2000 曝光/天；选热度约为 GPTs 一半、180 天内出现、SERP 前排是大站内页的词；提交到 AI 导航站拿外链。
- **结果**：把"赚第一美元"拆成可执行的找词与外链任务。

### 案例 2：日入 100 美元小目标（20241225）
- **方法论的使用**：$5 RPM → 2 万 PV → 约 6.6K UV（人均 3 PV）→ 约 4.6K 搜索点击 → 按 20% CTR 需日搜索约 2.3 万的词，或 5 个 5K 的词。
- **结果**：目标被转成"找几个多大的词"。

### 案例 3：群友练手（20261020 25 届毕业生第一个 100 美元；20260612 练手小游戏 30 天跑通）
- 群友按练手站思路先跑通流程，再在小词上拿到首笔收入（嘉宾/群友稿，作为佐证而非保证）。

## E — 可执行步骤 (Execution)

1. **定位用户在哪一级**
   - 问清：是否上线过站、是否有 GSC 数据、是否有收入。
   - 完成标准：明确属于 站1 / 站2 / 站3 / 放大期 之一。
2. **给出本级唯一目标与判定**
   - 站1：域名可访问 + GSC 已收录首页；站2：目标词进前 10；站3：GSC 日点击稳定 ≥100；放大期：按收入目标倒推。
   - 完成标准：目标可在 GSC/GA 中验证。
3. **给出本级的选词约束**（交给判词卡执行）
   - 站1 任意；站2 KD<10 且前 10 所需外链域名<10；站3 有搜索量的新词/蓝海词（趋势可见、intitle 供应少）。
4. **列本级动作清单与时间盒**：站1 一两天；站2 约一周；站3 约 3 周起；外链持续做。
5. **定义"换下一站"的条件**：达标即开下一站（不要等完美）；未达标先按 GSC 诊断卡排查，而不是马上换方向。
6. **输出**：一张阶段表（级别 / 目标 / 选词约束 / 动作 / 截止 / 验证方式）。

## B — 边界 (Boundary)

- 时间预期（一周进前 10、3 周 100 点击）是作者与群友经验值，2026 年起作者也承认新词竞争加剧、需要更多外链，不能当承诺。
- 案例多来自作者付费社群的成功者，有幸存者偏差。
- 不适用：已有成熟产品/品牌、靠付费投放或社媒冷启动的项目（路线不同）。
- 练手站不等于做垃圾站：仍需满足搜索意图，避免撞名仿冒（见 onpage 卡）。
